# 07-00 Flagged Accounts - 需求

## L0 摘要

固定格式（账号----密码----setup key）导入的账号自动标记为「被标记」；支持一键导出被标记账号（弹窗预览+复制+下载）、批量删除被标记账号；普通导出改为弹窗预览。

## L1 概览

### 目标

- 导入解析支持固定格式 `账号----密码----setup key`，导入后账号带 flagged 标记
- 账号列表显示「标记」徽章（紫色），导出被标记/删除被标记按钮按需出现
- 普通导出与「导出被标记」均改为弹窗：只读预览 textarea + 复制 + 下载 .txt
- 批量删除被标记账号（带确认弹窗，显示数量）

### 用户故事

- 作为账号管理员，我希望用固定格式快速导入账号并自动标记，以便与普通账号区分
- 作为运营人员，我希望一键预览并导出/删除所有被标记账号，以便批量清理

### 范围

**包含**：固定格式解析与标记、列表徽章、导出弹窗（全部/被标记）、批量删除被标记
**不包含**：手动标记/取消标记单个账号、被标记账号的其它批量操作（改密码等）

## L2 详情

### 详细需求

#### F-01 固定格式解析与标记
- 文本导入支持 `账号----密码----setup key`（四个连字符分隔，三段齐全才算），解析到 username/password/setupKey，`flagged=true`
- 普通格式（账号: xxx 等）不受影响，flagged 保持 false
- 预览表格新增「标记」列
- 验收：WHEN 导入固定格式文本 THEN 账号入库且 flagged=true；WHEN 普通格式 THEN flagged=false

#### F-02 标记标识与列表展示
- 账号记录新增 `flagged` 字段（明文非敏感），`listAccounts` 返回
- 列表行显示紫色「标记」徽章
- 验收：WHEN 存在 flagged 账号 THEN 列表显示徽章

#### F-03 导出被标记（弹窗）
- `GET /api/export?flagged=1` 仅导出被标记账号（格式与普通导出一致，可往返导入）
- 前端「导出被标记」按钮 → 弹窗：标题含数量、只读预览、复制、下载 .txt
- 验收：WHEN 点击导出被标记 THEN 预览仅含被标记账号且格式正确

#### F-04 普通导出弹窗化
- 原「导出」直接下载改为弹窗：预览 + 复制 + 下载
- 验收：WHEN 点击导出 THEN 弹窗预览全部账号，可复制或下载

#### F-05 批量删除被标记
- `POST /api/accounts/flagged/delete`：删除全部 flagged 账号（requirePasswordChanged 保护）
- 前端确认弹窗显示数量，删除后刷新列表
- 验收：WHEN 确认删除 THEN 全部被标记账号移除，普通账号保留

### 非功能性需求

- 兼容性：旧 vault 数据（无 flagged 字段）默认 false，不报错
- 安全性：删除为写操作，默认密码未改时禁止

### 边界与依赖

- 依赖 01-00 github-account-vault（账号 CRUD 与导出）
- 复制依赖浏览器剪贴板权限（真实浏览器可用，headless 受限）

### 验收标准

- [x] 固定格式导入→标记→徽章展示→导出被标记（弹窗预览/复制/下载）→批量删除全链路可用
- [x] 普通导出弹窗化，复制/下载可用
