# 01-00 Github Account Vault - 需求

## L0 摘要

GitHub 账号保险库：批量导入账号凭据（账号/邮箱/密码/setup key/otpauth/恢复码），网页端实时显示 2FA TOTP 码，管理 PAT 令牌，登录密码保护。

## L1 概览

### 目标

- 一键粘贴/上传批量导入 GitHub 账号信息（含恢复码多行列表），自动解析用户提供的文本格式
- 网页端以管理后台样式展示账号列表，每行实时显示当前 2FA 6 位动态码及 30 秒倒计时，一键复制
- 每个账号可保存/编辑 PAT 令牌（加密存储），支持一键复制
- 所有敏感字段（密码/setup key/恢复码/PAT）AES-256-GCM 加密存储，密钥由登录密码派生
- 首次启动设置登录密码，之后必须密码登录（JWT）才能访问账号数据

### 用户故事

- 作为批量 GitHub 账号使用者，我希望粘贴一段账号文本即可批量入库，以便免手动逐条录入
- 作为账号管理员，我希望网页端实时看到每个账号的 2FA 动态码，以便快速完成登录
- 作为安全敏感用户，我希望敏感凭据加密存储且需密码登录，以便数据库泄露也不暴露明文
- 作为日常使用者，我希望账号的 PAT 令牌保存在同一处并一键复制，以便免去反复查找

### 范围

**包含**：
- 登录密码首次设置与密码登录（JWT 会话）
- 文本/文件批量导入解析（用户给定格式 + JSON 格式）
- 账号列表 + 实时 TOTP 显示与倒计时 + 复制
- 账号详情查看（密码/setup key/恢复码）、编辑、删除
- PAT 令牌保存/编辑/复制
- 修改登录密码（重新派生密钥并重加密全部数据）
- 加密备份导出与导入
- 管理后台风格 UI（参考 ds2apiNew 设计系统：深色 slate + 琥珀色 accent）

**不包含**：
- 使用账号凭据自动登录 GitHub / 抓取账号状态
- 多用户体系（单管理员）
- PAT 自动调用 GitHub API 校验有效性

## L2 详情

### 详细需求

#### F-01 首次设置与密码登录
- 首次启动无密码时，页面进入"设置登录密码"流程；已设置则进入登录页
- 登录成功签发 JWT（7 天有效），失败返回 401
- 验收：WHEN 首次访问且未设置密码 THEN 提示设置密码；WHEN 输入错误密码 THEN 拒绝并提示；WHEN 输入正确密码 THEN 进入主界面

#### F-02 一键批量导入
- 支持粘贴多账号文本（分隔符为 ─ 分隔线或空行），自动解析：账号/邮箱/密码/setup key/otpauth/恢复码
- 恢复码支持多行缩进列表（每行形如 `xxxxx-xxxxx`）
- 支持上传 .txt/.json 文件；JSON 支持数组/对象格式
- 导入前显示解析预览（识别成功字段数），确认后入库；重复账号（按用户名）自动跳过或提示
- 验收：WHEN 粘贴用户提供的三段账号文本 THEN 全部字段（含 16 个恢复码）解析正确并入库；WHEN 上传 txt 文件 THEN 同样解析成功

#### F-03 实时 2FA 动态码
- 账号列表每行显示当前 TOTP 6 位码 + 30 秒倒计时（后端 RFC 6238 生成，secret 不下发前端）
- 倒计时归零自动刷新；支持点击复制动态码
- 验收：WHEN 查看列表 THEN 每个含 secret 的账号显示 6 位码与倒计时；WHEN 倒计时归零 THEN 码自动更新为新的 6 位码

#### F-04 账号详情与凭据管理
- 点击账号展开详情：显示邮箱、密码、setup key、otpauth、恢复码（均默认掩码，可一键复制、可显示明文）
- 支持编辑账号信息、删除账号
- 验收：WHEN 点击账号 THEN 展开详情且敏感字段默认掩码；WHEN 点击复制 THEN 明文进入剪贴板；WHEN 删除 THEN 确认后移除且列表刷新

#### F-05 PAT 令牌管理
- 每个账号可保存一个 PAT（加密存储），列表显示简短预览，可复制完整令牌
- 验收：WHEN 保存 PAT THEN 列表显示预览且复制可得完整值；WHEN 重启服务 THEN PAT 仍可正确解密读取

#### F-06 修改密码与备份
- 设置页可修改登录密码：旧密码验证 → 用新密码重新派生密钥 → 全量重加密
- 支持导出加密备份（含密文+盐，需登录密码才可解密）与导入备份
- 验收：WHEN 修改密码 THEN 旧密码失效新密码可登录且所有账号数据仍可读；WHEN 导出备份后导入另一实例（相同密码）THEN 数据完整恢复

### 非功能性需求

- 性能：列表接口响应 < 300ms；批量 TOTP 生成 < 50ms（百级账号）
- 兼容性：Node.js >= 22；现代浏览器（Chrome/Edge/Safari 近两年版本）
- 安全性：敏感字段 AES-256-GCM；密码 scrypt 哈希；JWT 签名密钥随机生成；API 全部鉴权

### 边界与依赖

- 后端依赖 Node.js 内置 crypto（scrypt/HMAC-SHA1/AES-256-GCM），无第三方加解密库
- 前端复用 ds2apiNew 设计系统样式（tailwind CSS 变量主题），不引入额外 UI 库

### 验收标准

- [x] 首次启动设置密码后，未登录访问任何 /api 返回 401
- [x] 粘贴 3 个示例账号文本，全部字段（含恢复码 16 条）入库且 TOTP 与标准算法一致
- [x] 列表页实时显示 6 位动态码与倒计时，归零自动刷新，可复制
- [x] 密码/setup key/恢复码/PAT 均为掩码展示，解密后复制正确
- [x] 修改密码后旧密码失效、数据可读；重启服务数据不丢、仍可登录
