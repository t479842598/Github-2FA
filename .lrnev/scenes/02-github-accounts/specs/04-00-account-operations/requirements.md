# 04-00 Account Operations - 需求

## L0 摘要

账号运营增强：操作审计日志、GitHub 会话/PAT 有效性检测、账号健康检查、PAT 全生命周期管理、批量导出（用户导入格式）、恢复码使用标记、账号标签分组。

## L1 概览

### 目标

- 审计日志：记录登录/改密/导入/账号变更/PAT 生成/备份等关键操作，可查看
- 会话检测：用保存的 GitHub cookie 探测会话是否仍有效
- 健康检查：批量检测每个账号的会话/PAT 状态，列表可视
- PAT 管理：查看账号名下全部 PAT（名称/权限/过期/最后使用），可撤销
- 批量导出：按用户导入文本格式导出全部账号（可复制/下载）
- 恢复码标记：恢复码逐条标记"已使用"，用过的自动置灰
- 标签分组：账号打标签，按标签筛选

### 用户故事

- 作为管理员，我希望查看操作日志，以便发现异常登录/操作
- 作为账号使用者，我希望知道哪些账号的 GitHub 会话已失效、PAT 是否可用，以便及时处理
- 作为谨慎用户，我希望撤销不再使用的 PAT，以便缩小泄露面
- 作为迁移用户，我希望按导入格式导出账号，以便换机器时无缝迁移
- 作为多账号用户，我希望标记已用恢复码、按标签分组，以便管理大量账号

### 范围

**包含**：审计日志查看与清理、会话/PAT 有效性探测、健康检查报告、PAT 列表与撤销、文本格式导出、恢复码使用标记、标签筛选
**不包含**：审计日志的防篡改签名、PAT 自动续期、标签云统计

## L2 详情

### 详细需求

#### F-01 审计日志
- 记录事件：登录成功/失败、修改密码、导入、添加/编辑/删除账号、生成 PAT、GitHub 登录/退出、备份导出/导入、健康检查
- 字段：时间、动作、对象（账号名）、来源 IP、结果
- 设置页新增「审计日志」面板：倒序列表 + 清空
- 验收：WHEN 完成上述任一操作 THEN 日志出现对应记录；WHEN 清空 THEN 列表为空

#### F-02 GitHub 会话有效性检测
- 用保存 cookie 请求 GitHub 页面探测：有效 → 返回用户名；失效 → 标记需重新登录
- GitHub 页「检测」按钮 + 账号状态显示"有效/失效"
- 验收：WHEN 会话有效 THEN 状态为有效；WHEN cookie 过期 THEN 状态为失效且不误报

#### F-03 账号健康检查
- 批量：会话有效性 + PAT 有效性（用 PAT 调 api.github.com/user）
- 结果：{会话: 有效/失效/未登录, PAT: 有效/失效/未配置}，账号列表或 GitHub 页显示徽章
- 验收：WHEN 点击健康检查 THEN 全部账号状态返回并展示

#### F-04 PAT 全生命周期管理
- 解析 /settings/tokens 列表：名称、scopes、过期时间、最后使用
- 支持撤销单个 PAT（表单提交），撤销后从列表消失
- 验收：WHEN 打开管理弹窗 THEN 显示全部 PAT；WHEN 撤销 THEN GitHub 侧删除且列表刷新

#### F-05 批量导出（导入格式）
- 导出为文本：与导入格式一致（账号/邮箱/密码/setup key/otpauth/恢复码/PAT，块间 ────）
- 支持下载 .txt 与复制
- 验收：WHEN 导出 THEN 文本可直接被本系统导入回（往返一致）

#### F-06 恢复码使用标记
- 恢复码逐条标记已用/未用（加密存储），详情展示置灰 + 徽章
- 点击切换状态需确认
- 验收：WHEN 标记某条已用 THEN 详情置灰且刷新后保持

#### F-07 账号标签分组
- 账号可设置多个标签（逗号分隔），列表显示标签徽章，可按标签筛选
- 验收：WHEN 设置标签 THEN 列表展示并可筛选

#### F-08 导入去重
- 导入时逐条去重：① 用户名已存在 → 跳过；② 密码、setup key、otpauth 与库内某账号完全一致 → 跳过（账号不同也算重复）
- 仅导入库内不存在（账号与内容均不重复）的账号；解析预览标注哪些条目会因重复被跳过
- 验收：WHEN 重复导入同一批账号 THEN 全部跳过、不产生重复记录；WHEN 导入同凭据不同用户名 THEN 按内容重复跳过；WHEN 导入全新账号 THEN 正常入库

### 非功能性需求

- 健康检查/PAT 检测批量执行时 GitHub 请求间隔 ≥ 500ms，避免限流
- 审计日志最多保留 2000 条（超出自动裁剪）

### 验收标准

- [ ] 关键操作全部有日志且可在设置页查看/清空
- [ ] 会话检测与健康检查返回准确状态
- [ ] PAT 列表可查看与撤销
- [ ] 导出文本可往返导入
- [ ] 恢复码标记与标签筛选可用
- [ ] 导入去重：重复账号/重复内容自动跳过，只导入库内没有的账号
