# 0001. 凭据保险库加密与存储方案

## 状态

proposed

## 背景

GitHub 账号保险库需存储密码/setup key/恢复码/PAT 等敏感凭据，且需密码登录保护、网页端实时显示 TOTP。要求零第三方安全依赖、单文件可备份迁移。

## 决策

1) 存储用单 JSON 文件 data/vault.json，敏感字段 AES-256-GCM 字段级加密（每字段独立 12B IV + authTag）；2) 数据密钥由登录密码 scrypt(16384,8,1) 派生，meta.salt 同时作为密码哈希盐；3) TOTP 由后端生成，secret 永不下发前端；4) JWT 用独立随机密钥 HMAC-SHA256，tokenVersion 机制保证改密码后旧会话立即吊销

## 备选方案

- SQLite 存储（需要原生依赖，备份复杂）
- 前端生成 TOTP（secret 需下发前端，安全面扩大）
- AES 整文件加密（无法按需解密字段，改密码需重写全文件）

## 后果

改密码需全量重加密（百级账号毫秒级）；备份文件本身为密文，恢复需登录密码；单文件备份=全量迁移；丢失密码则数据不可恢复（不可找回）
